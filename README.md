# Commute Verbal

Hands-free GRE vocab for your commute. It reads a word, gives you a moment to recall it, reads the
definition, an example and a memory hook, then you say how well you knew it from 1 (nailed it) to 5 (blank).
Weak words come back every day until you've got them.

**Use it:** https://aidenwright973.github.io/commute-verbal/ — open in Safari, Share → Add to Home Screen,
then tap "Start hands-free ride".

**Develop:** edit `src/app.html` or `data/words.json`, then `npm install && npm test` (builds `index.html`
and runs the simulations). See `CLAUDE.md` for how everything fits together.
